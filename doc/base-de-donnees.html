MySQL / MariaDB

Mettre en place la base de données

Créez une base vide. N’importez aucun fichier SQL : l’assistant exécute les migrations Laravel et les seeders.

Dans cPanel

  1. Ouvrez Bases de données MySQL.
  2. Créez une base, par exemple chanlog. Le nom réel sera souvent compte_chanlog.
  3. Créez un utilisateur et un mot de passe fort.
  4. Ajoutez l’utilisateur à la base avec Tous les privilèges.
  5. Hôte : en général localhost. Port : 3306.

Dans Webuzo

  1. Menu MySQL Database (ou phpMyAdmin).
  2. Create Database + Create User.
  3. Associez l’utilisateur à la base (ALL PRIVILEGES).
  4. Host localhost.

En ligne de commande

CREATE DATABASE chanlog CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'chanlog'@'localhost' IDENTIFIED BY 'MotDePasseFort';
GRANT ALL PRIVILEGES ON chanlog.* TO 'chanlog'@'localhost';
FLUSH PRIVILEGES;

Erreur « Connexion MySQL impossible » Mauvais préfixe cPanel, mot de passe avec caractères spéciaux mal copiés, ou hôte incorrect (127.0.0.1 au lieu de localhost, ou l’inverse). L’installeur teste PDO avant d’écrire le .env.

Ce que l’installeur crée ensuite

  • Toutes les tables via php artisan migrate
  • Les plans (free, etc.) via PlanSeeder
  • Un seed admin via AdminSeeder, puis votre superadmin (email du formulaire)
  • Un tenant default si aucun n’existe
  • Sessions, cache et files d’attente en base (SESSION_DRIVER=database, etc.)
SQLite Le .env.example local utilise SQLite. En production, l’installeur force DB_CONNECTION=mysql. Ne restez pas sur SQLite pour un site public.
