Installer Evolora sur Webuzo

Webuzo (souvent ports :2004 utilisateur ou :2002 admin) offre les mêmes briques : fichiers, MySQL, PHP, domaine. Evolora ne s’installe pas via Softaculous : on déploie les fichiers puis on ouvre /install.

Ajouter le domaine

Webuzo → Website / Domain → Add Domain. Indiquez changelog.monsite.fr. Repérez le chemin, en général /home/USER/www/changelog.monsite.fr ou /home/USER/public_html.

Choisir PHP 8.2+

Webuzo → PHP / MultiPHP. Assignez 8.2 ou 8.3 au domaine. Activez les extensions listées dans Prérequis (pdo_mysql, mbstring, curl, etc.).

Déposer les fichiers

File Manager, FTP ou SFTP. Extraire le projet pour que artisan, app/ et public/ soient à la racine du site. Évitez d’avoir un sous-dossier ChangeLog/ChangeLog/….

Document Root = public

Si Webuzo le permet (Domain → Edit / Document Root), pointez vers …/public. Sinon, conservez le .htaccess racine fourni avec le projet (Apache est le défaut Webuzo).

Base MySQL

Webuzo → MySQL ou phpMyAdmin. Créez une base vide, un utilisateur, privileges ALL, hôte localhost. Gardez les identifiants pour l’assistant.

SSL

Webuzo → SSL / Let’s Encrypt. Émettez un certificat pour le domaine (et plus tard un wildcard si vous utilisez les sous-domaines clients).

Assistant Evolora

Navigateur : https://changelog.monsite.fr/install. Même wizard que sur cPanel. Si une page blanche apparaît, regardez storage/logs/laravel.log et les droits d’écriture.

SSH Webuzo (si activé)

cd /home/USER/www/changelog.monsite.fr
composer install --no-dev --prefer-dist --optimize-autoloader
chmod -R 775 storage bootstrap/cache
Softaculous « Laravel » N’installez pas un Laravel vide via Softaculous : vous auriez une autre application. Uploadez le package Evolora, puis utilisez son wizard /install.
