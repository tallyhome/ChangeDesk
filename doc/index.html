Installer l’application sur un serveur web

Ce guide explique comment déployer Evolora sur cPanel, Webuzo, Plesk, Apache, Nginx ou un VPS. L’application inclut un assistant web : vous n’avez pas besoin de lancer Artisan à la main.

Assistant /install confirmé PHP 8.2+ MySQL / MariaDB Laravel 12
Oui, il y a un auto-installeur (Install Wizard) Evolora embarque un assistant complet à l’adresse /install. S’il n’existe pas encore de fichier storage/app/installed ni de .env avec une clé, le site redirige automatiquement vers cet assistant.
Uploader les fichiers→ Créer la base MySQL→ Ouvrir /install→ Superadmin→ Connexion

1. Vérifier le serveur

PHP 8.2, extensions Laravel, droits d’écriture sur storage/ et bootstrap/cache.

Ce que fait l’installeur automatiquement

  • Vérifie PHP 8.2+ et les extensions (PDO MySQL, OpenSSL, Mbstring, Curl…)
  • Teste la connexion MySQL puis écrit le fichier .env
  • Génère APP_KEY, lance les migrations et les seeders (plans + admin)
  • Crée le compte superadmin et un projet tenant par défaut
  • Crée le lien storage et le fichier storage/app/installed

Méthode recommandée : Document Root = public/

Dans le panneau d’hébergement, pointez le domaine vers le dossier public du projet, pas vers la racine Laravel. Cela empêche d’exposer .env, vendor/ et le code source.

/home/USER/changelog.votredomaine.fr/public

Si le panneau refuse de changer le Document Root, utilisez le fichier .htaccess fourni à la racine du projet : il redirige tout le trafic vers public/.
