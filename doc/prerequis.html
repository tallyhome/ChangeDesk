Avant d’installer

Prérequis serveur

L’étape 2 de l’assistant (/install/requirements) contrôle ces points. Corrigez-les avant de continuer, sinon l’installation s’arrête.

Droits d’écriture

L’assistant doit pouvoir écrire :

  • storage/ (logs, cache, fichier installed)
  • bootstrap/cache/
  • le fichier .env à la racine, ou le dossier racine s’il n’existe pas encore
chmod -R 775 storage bootstrap/cache
# Si besoin, propriétaire = utilisateur du serveur web
chown -R USER:USER storage bootstrap/cache
Node.js n’est pas obligatoire en production Les assets sont déjà compilés dans public/. N’uploadez pas node_modules/. Composer en mode --no-dev suffit si vendor/ est absent.

Ce qu’il ne faut pas uploader

  • node_modules/
  • archives .zip du projet (elles gonflent le compte)
  • vieux backups dans storage/app/backups/
  • le dossier .git/ (optionnel, inutile en prod)
