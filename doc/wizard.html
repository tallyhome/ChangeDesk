Install Wizard

L’auto-installeur Laravel est bien présent

Evolora n’utilise pas Softaculous. Il a son propre assistant web, intégré à l’application. C’est la méthode officielle pour installer le logiciel sur n’importe quel hébergement PHP.

Vérifié dans le code source Contrôleur app/Http/Controllers/InstallController.php, routes /install, vues resources/views/install/, middleware RedirectIfNotInstalled. Si l’app n’est pas encore installée, toute visite est redirigée vers /install.

Comment y accéder

https://votre-domaine/install
https://votre-domaine/install/requirements
https://votre-domaine/install/database

Après une installation réussie, /install répond 404 : le fichier storage/app/installed bloque une réinstallation accidentelle.

Les 4 étapes

Accueil

Présente l’assistant. Rappel : PHP 8.2+, base MySQL prête, Document Root vers public/.

Prérequis

Chaque extension et droit d’écriture est affiché OK / KO. Tant qu’un point est KO, le bouton Continuer reste bloqué.

Configuration

Vous saisissez l’URL, le domaine central, les identifiants MySQL et le compte superadmin (mot de passe 8 caractères minimum, avec confirmation).

Terminé

Lien vers la connexion et la vitrine. Configurez ensuite Stripe / PayPal dans le .env si vous activez la facturation.

Actions exécutées côté serveur

1. Test PDO MySQL
2. Écriture du fichier .env
3. php artisan key:generate --force
4. php artisan config:clear
5. php artisan migrate --force
6. php artisan db:seed --class=PlanSeeder
7. php artisan db:seed --class=AdminSeeder
8. php artisan storage:link
9. Création / mise à jour du superadmin
10. Création du tenant « default » (plan free) s’il n’existe pas
11. Fichier storage/app/installed
12. php artisan config:cache
Redirection automatique Le middleware ignore /install et /up. S’il existe déjà un .env avec APP_KEY, l’installeur n’est pas forcé (déploiement déjà configuré). Sinon, tout le site renvoie vers /install.

Installation manuelle (SSH, optionnelle)

Si vous préférez la ligne de commande plutôt que le wizard :

cp .env.example .env
php artisan key:generate
# Éditer DB_* APP_URL CENTRAL_DOMAIN dans .env
php artisan migrate --force
php artisan db:seed --class=PlanSeeder --force
php artisan db:seed --class=AdminSeeder --force
php artisan storage:link
# Créer ensuite storage/app/installed pour désactiver le wizard

En hébergement mutualisé sans SSH, restez sur /install.
