Autres serveurs

Apache, Nginx, Plesk et VPS

Le principe reste identique : le serveur web ne doit exposer que public/, PHP 8.2 exécute index.php, puis vous ouvrez /install.

Plesk

  1. Domaines → Ajouter un domaine.
  2. Hébergement → Racine du document : httpdocs/public (après upload) ou créez le domaine puis uploadez dans httpdocs et changez la racine en public.
  3. PHP : 8.2 / 8.3, FPM recommandé.
  4. Bases de données → MySQL, utilisateur avec tous les droits.
  5. SSL Let’s Encrypt.
  6. https://domaine/install.

Apache (VPS)

Activez mod_rewrite et AllowOverride All pour que public/.htaccess fonctionne.

<VirtualHost *:80>
    ServerName changelog.monsite.fr
    ServerAlias *.changelog.monsite.fr
    DocumentRoot /var/www/chanlog/public

    <Directory /var/www/chanlog/public>
        AllowOverride All
        Require all granted
    </Directory>

    ErrorLog ${APACHE_LOG_DIR}/chanlog-error.log
    CustomLog ${APACHE_LOG_DIR}/chanlog-access.log combined
</VirtualHost>
sudo a2enmod rewrite
sudo systemctl reload apache2

Nginx (VPS)

server {
    listen 80;
    server_name changelog.monsite.fr *.changelog.monsite.fr;
    root /var/www/chanlog/public;
    index index.php;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        include fastcgi_params;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        fastcgi_pass unix:/run/php/php8.2-fpm.sock;
    }

    location ~ /\.(?!well-known).* {
        deny all;
    }
}

Puis Certbot pour HTTPS. Adaptez le socket PHP-FPM à votre version.

Déploiement VPS type

cd /var/www
# cloner ou extraire Evolora dans /var/www/chanlog
cd chanlog
composer install --no-dev --prefer-dist --optimize-autoloader
chown -R www-data:www-data storage bootstrap/cache
chmod -R 775 storage bootstrap/cache
# Configurer le vhost, puis ouvrir https://domaine/install
Ne jamais pointer le vhost sur la racine Laravel /var/www/chanlog comme Document Root exposerait .env et vendor/. Toujours …/public.
